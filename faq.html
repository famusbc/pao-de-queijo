Como retirar seu pão de queijo

Guia rápido do aplicativo do Programa Faculdade Municipal São Bernardo do Campo

O passo a passo

1

Aponte a câmera para o QR Code

O QR Code fica exposto na entrada da faculdade. Abra a câmera do celular, aponte e toque no link que aparecer.

2

Informe seu RA ou CPF

Digite só os números, sem pontos ou traços. Se você ainda não sabe seu RA, pode usar o CPF.

Código de retirada
RA ou CPF
Acessar
3

Guarde o código de 4 dígitos

Ele aparece com o seu nome. É esse número que você vai apresentar na copa.

Bem-vindo(a)
Seu nome aparece aqui
Seu curso · 18:32
Código de retirada
6277
4

Apresente o código na copa

Mostre a tela ou diga o número para quem está atendendo. Pronto — é só retirar.

O que você precisa saber

O QR Code muda todos os dias

Cada dia tem o seu. O de ontem não funciona hoje, e nenhum link salvo nos favoritos vai funcionar no dia seguinte. Sempre escaneie o QR Code que está exposto na entrada naquele dia.

O código de ontem não vale hoje

Todo dia é um código novo. Anotar o número de um dia para usar no outro não funciona — o sistema não reconhece.

Uma unidade por dia

Cada aluno tem direito a um pão de queijo por dia de oferta. O benefício não acumula de um dia para o outro.

Seu código é só seu

Ele é pessoal e intransferível. A identificação no sistema deve ser sempre a sua.

Não dá para gerar outro no mesmo dia

Se você pedir de novo, o sistema mostra o mesmo número. Por isso, guarde o seu com atenção até a hora de retirar.

Fechou o app? Abra de novo

O código fica guardado no seu celular durante o dia. Se você fechar sem querer, é só abrir novamente que ele aparece na hora, sem precisar digitar nada.

Se aparecer alguma mensagem

Acesse pelo QR Code da entrada
Você abriu o app por um link antigo ou pelos favoritos. Escaneie o QR Code exposto hoje na entrada.
Não encontramos esse número
Confira se digitou certo, só números, sem pontos ou traços. Tente o CPF se estava usando o RA. Se continuar, procure a secretaria — seu cadastro pode estar pendente.
Fora do horário
A geração do código funciona apenas durante o horário de distribuição, que aparece na tela do app quando você entra pelo QR Code.
Sem conexão
Verifique sua internet e toque em tentar de novo. Se você já gerou seu código hoje, ele continua valendo e aparece mesmo sem conexão.

Perguntas frequentes

Preciso escanear o QR Code todos os dias?
Sim. Todo dia tem um QR Code diferente. Guardar o link nos favoritos não adianta: no dia seguinte ele deixa de funcionar e você vai precisar escanear o novo, exposto na entrada.
Por que preciso estar na faculdade para gerar o código?
Porque o QR Code fica exposto no local. É assim que o programa garante que a retirada seja feita por quem está presente naquele dia.
Perdi meu código. Consigo outro?
O sistema mostra sempre o mesmo número para você naquele dia. Basta abrir o app novamente — o código fica guardado no seu celular. Se não aparecer, escaneie o QR Code de novo e informe seu RA ou CPF.
Posso pegar para um colega que não veio?
Não. O código é pessoal e intransferível, e cada aluno tem direito a uma unidade por dia. A identificação no sistema deve ser sempre a sua.
Não sei meu RA. E agora?
Use o CPF, só os números. Funciona da mesma forma.
Uso nome social. Vai aparecer qual nome?
O seu nome social. Sempre que ele estiver cadastrado, é ele que aparece na tela, no comprovante e para quem atende na copa.
Meu celular está sem internet. O que faço?
Se você já gerou o código hoje, ele aparece mesmo sem conexão — é só abrir o app. Se ainda não gerou, use a rede da faculdade ou peça orientação na copa.
Todo dia tem pão de queijo?
A distribuição acontece nos dias definidos pelo programa. Ao entrar pelo QR Code da entrada, o app mostra se hoje é dia de oferta e qual o horário.
Preciso instalar algum aplicativo?
Não. Tudo funciona pelo navegador do celular, direto do QR Code. Não há nada para baixar.
